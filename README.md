# NORD CLEAN — Лендинг химчистки с доставкой

Одностраничный лендинг для вымышленной компании NORD CLEAN. Сервис химчистки, стирки и ухода за вещами с доставкой по Санкт-Петербургу.

**Демо:** [chatorsn.github.io/nord_clean_landing](https://chatorsn.github.io/nord_clean_landing/)

---

## О проекте

Цель страницы — объяснить услуги компании и мотивировать пользователя оставить заявку. Лендинг содержит 8 основных блоков: первый экран, о компании, услуги, процесс работы, преимущества, аудитория, форма заявки, контакты и FAQ.

---

## Структура блоков

- **Hero** — заголовок, подзаголовок, описание, CTA-кнопка, карточки категорий услуг
- **О компании** — полный цикл работы, индивидуальный подход, аккуратность
- **Услуги** — химчистка, стирка, уход за обувью, корпоративные заказы, доставка
- **Процесс** — 5 этапов от заявки до возврата в виде timeline
- **Преимущества** — доставка, индивидуальный подход, деликатные материалы, упаковка, регулярное обслуживание, коммуникация
- **Аудитория** — частные клиенты, семьи, деловые клиенты, малый бизнес
- **Форма заявки** — имя, телефон с маской, тип услуги, комментарий
- **FAQ** — 5 вопросов в аккордеоне
- **Контакты** — телефон, email, город, график работы
